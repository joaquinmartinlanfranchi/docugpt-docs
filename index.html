Documentación funcional · v1

DocuGPT

Plataforma multi-tenant de procesamiento inteligente de documentos: combina OCR tradicional con IA generativa para leer, interpretar y transformar facturas, contratos, pólizas, resúmenes bancarios, CVs y cualquier otro documento de negocio en datos estructurados y accionables, que luego se envían automáticamente a otros sistemas mediante conectores configurables. La configuración se define en lenguaje natural, pensada para que la use y mantenga un usuario de negocio, sin intervención técnica constante.

EntradaEmail · API · Drive SalidaJSON + conectores OCRAzure (Gemini p/ manuscritos) FormatosPDF · PNG · JPG

Vocabulario del producto 02

Siete ideas que explican casi todo lo que hace DocuGPT puertas adentro.

Tenant / Organización

Base de datos aislada por empresa. Una misma empresa puede tener varios tenants, con entornos separados de desarrollo y producción.

Tipo de contenido

Define los campos a extraer y las reglas de formato de cada variable — por ejemplo, un CUIT a 11 dígitos sin guiones.

Discovery

Genera el esquema de un tipo de contenido en minutos a partir de al menos 3 documentos de ejemplo, infiriendo incluso variables calculadas.

Conector

Acción posterior al procesamiento (webhook o código embebido) que solo se ejecuta si el documento quedó válido. Detalle en Conectores.

Confidence score

Certeza predictiva del modelo sobre cada dato extraído — orienta qué campos conviene revisar a mano.

Plan / Consumo

Cada tenant tiene un plan con vigencia y tope de páginas. Sin plan activo, el procesamiento se rechaza. Detalle en Organización y planes.

OCR

Motor Azure por defecto; puede configurarse Gemini u otro LLM avanzado para admitir manuscritos.
